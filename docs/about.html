summary

I'm a Lead Security Engineer on the cloud security team at Paytm, working on cloud and Kubernetes security with CSPM, CWPP, Prisma Cloud, and Cortex. Before that I spent 4.5+ years as a DevOps and DevSecOps engineer designing, securing, and operating production Kubernetes (GKE, EKS, bare-metal) on GCP and AWS.

That work covers Terraform IaC, CI/CD (Jenkins, GitHub Actions, ArgoCD), observability, and incident response, plus air-gapped clusters where nothing reaches the internet. Working at the seam between cloud architecture and cybersecurity, I've cut deployment time by 50% and kept 30+ production servers at 99.9% uptime. I'm CKA and CKAD certified, and currently pursuing an M.Tech in Cloud Computing at IIT Patna.
